# 地震情報取得元の仕様・移行の経緯

地震情報の取得方式に関する外部サービスの仕様・制約と、方式選定の理由をまとめたもの。実装は `src/earthquake_source.py` を参照。

## JMAポーリングからP2P地震情報WebSocketへの移行

当初は JMA の `list.json` を定期ポーリングしていたが、更新検知がポーリング間隔ぶん遅延するため、リアルタイム性を高める目的で [P2P地震情報](https://www.p2pquake.net/) の WebSocket API(`wss://api.p2pquake.net/v2/ws`)に切り替えた。地震発生後ほぼ即座に `code: 551` のメッセージが配信される。

起動直後に表示する初期値のみ、従来通り JMA `list.json` を1回取得して埋める(WebSocketは「今後発生したイベント」のみを配信するため)。

## P2P地震情報の同時接続数制限

2026年6月以降、**IPアドレスあたりの同時接続数が2に制限**されている(参照: [レート制限強化について](https://p2pquake.hatenablog.jp/entry/2026/05/29/005109))。`EarthquakeStream` の指数バックオフ再接続はこの制約を踏まえた設計。

このリンク先の告知内容が変更・撤回される可能性があるため、実際の制限値は必要に応じて公式アナウンスで再確認すること。
